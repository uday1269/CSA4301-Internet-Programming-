Question 1: Responsive Navigation Bar Design – 4 Marks

(a) Important Components

An online shopping website needs a clear navigation system so that customers can quickly move between important areas. The navigation can contain branding, shopping links, search, account controls and a mobile menu.

  • Website branding or logo
  • Home and shopping categories
  • Search facility
  • Shopping cart
  • Customer account option
  • Mobile hamburger control

(b) Responsive Layout Technique

Flexbox is useful for placing the logo, navigation items and cart beside one another. CSS media queries can modify the navigation when the available screen width becomes smaller.

(c) Hamburger Navigation

On a mobile screen, the navigation links are initially hidden. The hamburger button becomes visible and JavaScript changes the navigation state when the button is pressed.

(d) Usability Improvements

The navigation should have clear labels and sufficient spacing. Additional improvements include a visible search field, category menus, keyboard navigation, suitable touch targets and an active-link indicator.

Question 2: Product Hover Effect – 4 Marks

(a) CSS Properties

The hover effect can be designed using transform, transition, box-shadow, opacity and border properties. These properties help create a smooth visual response.

(b) Transition and Animation

The transition property makes the change gradual rather than immediate. A product card can slightly move upward or increase in size while a shadow is added when the pointer moves over it.

(d) Performance and User Experience

Hover animations should remain simple and quick. CSS-based transitions are preferable for common visual effects because they are efficient. Very large animations should be avoided. The interface must also remain usable on touch devices where hover behaviour is not available.

Question 3: Flexbox vs Grid for Dashboard – 4 Marks

(a) Dashboard Requirements

An e-commerce dashboard can contain a navigation sidebar, heading area, summary information and other data blocks. Therefore, both horizontal and vertical relationships need to be managed.

(b) Flexbox and Grid Comparison

  • Flexbox: Suitable when elements mainly need to be arranged in one direction such as a row or a column.
  • CSS Grid: More appropriate when the interface requires simultaneous control of rows and columns.

(c) Chosen Layout: CSS Grid

CSS Grid is selected for this dashboard because it provides direct control over two-dimensional page structure. It makes it easier to position the sidebar, header and information cards.

Question 4: Mobile-First Blog Layout – 4 Marks

(a) Main Blog Components

  • Website header
  • Navigation area
  • Main article section
  • Individual posts
  • Sidebar information
  • Categories
  • Footer

(b) Mobile-First Approach

A mobile-first design begins with the smallest practical screen size. Content is arranged vertically in a single column so that it remains easy to read on phones.

(c) Adapting for Larger Screens

Media queries can be introduced after the basic mobile structure. As the screen becomes wider, the design can add columns, increase spacing and use the extra available area.

(d) Accessibility and Readability

Blog content should use readable typography, suitable colour contrast, meaningful headings and descriptive links. Images should contain alternative text and interactive elements should be accessible through the keyboard.

Question 5: JavaScript Event Handling for Dynamic Menu – 4 Marks

(a) JavaScript Events

Menu interaction can use events such as click, mouseover, mouseout, focus and keydown. The click event is commonly used for opening and closing a menu.

(b) Menu Toggle Method

JavaScript can change the visibility of a menu by adding or removing a CSS class. The CSS class determines whether the menu is currently displayed.

(c) Interactive Menu

  • Home
  • Shop Products
  • Special Offers
  • Account
  • Customer Support

(d) Performance and Improvements

Event listeners should be attached only where necessary. Unnecessary DOM updates should be avoided. Accessibility can be improved by maintaining ARIA states, supporting keyboard interaction and providing visible focus indicators. The menu can also be closed after a navigation option is selected.
